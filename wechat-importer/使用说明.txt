小象CRM - 微信聊天记录导入工具 使用说明
==========================================

【快速开始】只需 3 步：

第 1 步：安装依赖
  → 双击运行 "0_安装依赖.bat"
  → 等待安装完成

第 2 步：获取数据库密钥
  方式 A（推荐）：使用 WeChatMsg 工具
    1. 下载：https://github.com/LC044/WeChatMsg/releases
    2. 运行 WeChatMsg.exe，点击「获取信息」
    3. 复制显示的 Key（密钥）
    4. 在本目录新建文件 wechat_key.txt，把密钥粘贴进去保存

  方式 B：运行导入脚本时按提示输入

第 3 步：导入聊天记录
  → 双击运行 "1_一键导入聊天记录.bat"
  → 按提示操作，选择要导入的联系人

【实时监控】（可选，持续同步新消息）
  → 双击运行 "2_启动实时监控.bat"
  → 保持窗口打开，会自动同步新消息
  → 按 Ctrl+C 停止

【注意事项】
1. 微信必须保持登录状态
2. 首次运行建议以管理员身份右键 → 以管理员身份运行
3. 导入过程中不要关闭微信
4. 所有操作都是只读的，不会修改微信的任何内容

【CRM 系统配置】
  如果你的 CRM 不在本机运行，请修改脚本中的 CRM_BASE_URL
  默认 API Key: wechat-monitor-2026-secret-key

【常见问题】
Q: 提示解密失败？
A: 检查密钥是否正确，确保 wechat_key.txt 里没有多余的空格或换行

Q: 找不到微信数据目录？
A: 打开微信 → 设置 → 文件管理 → 查看文件夹位置

Q: 实时监控会耗电/占资源吗？
A: 不会，每 10 秒只读取一次数据库，资源占用极小
